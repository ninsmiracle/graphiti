# Graphiti 社区系统流程图

## 1. 全量构建流程 (build_communities)

```
┌─────────────────────────────────────────────────────────────────┐
│                      开始：build_communities                     │
└───────────────────────────────┬─────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│              步骤1: get_community_clusters(driver)               │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │ 1.1 查询所有 group_ids (如果未指定)                        │  │
│  │     MATCH (n:Entity) WHERE n.group_id IS NOT NULL          │  │
│  │     RETURN collect(DISTINCT n.group_id)                    │  │
│  └───────────────────┬───────────────────────────────────────┘  │
│                      │                                           │
│                      ▼                                           │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │ 1.2 对每个 group_id:                                       │  │
│  │   a. 获取该组的所有 EntityNode                            │  │
│  │   b. 为每个节点查询邻居和边权重                           │  │
│  │      → 构建 projection: {uuid: [Neighbor列表]}            │  │
│  └───────────────────┬───────────────────────────────────────┘  │
│                      │                                           │
│                      ▼                                           │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │ 1.3 执行 label_propagation(projection)                     │  │
│  │     → 返回 cluster_uuids: [[uuid1, uuid2], [uuid3, ...]]  │  │
│  └───────────────────┬───────────────────────────────────────┘  │
│                      │                                           │
│                      ▼                                           │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │ 1.4 并发获取完整的 EntityNode 对象                        │  │
│  │     → community_clusters: [[EntityNode, ...], ...]        │  │
│  └───────────────────────────────────────────────────────────┘  │
└───────────────────────────────┬─────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│         步骤2: 并发构建社区 (受信号量限制，最多10个并发)          │
│  ┌──────────────────┐  ┌──────────────────┐  ┌──────────────┐  │
│  │ build_community  │  │ build_community  │  │    ...       │  │
│  │   (cluster 1)    │  │   (cluster 2)    │  │              │  │
│  └────────┬─────────┘  └────────┬─────────┘  └──────┬───────┘  │
│           │                     │                    │           │
│           └─────────────────────┴────────────────────┘           │
│                                 │                                │
└─────────────────────────────────┼────────────────────────────────┘
                                  │
                                  ▼
┌─────────────────────────────────────────────────────────────────┐
│              步骤3: 收集结果并保存到数据库                        │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │ community_nodes: [CommunityNode1, CommunityNode2, ...]    │  │
│  │ community_edges: [CommunityEdge1, CommunityEdge2, ...]    │  │
│  └───────────────────────────────────────────────────────────┘  │
└───────────────────────────────┬─────────────────────────────────┘
                                │
                                ▼
                            返回结果
```

## 2. 单个社区构建流程 (build_community)

```
┌─────────────────────────────────────────────────────────────────┐
│              输入: community_cluster (EntityNode列表)            │
└───────────────────────────────┬─────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│          步骤1: 提取所有实体的摘要                                │
│          summaries = [entity.summary for entity in cluster]      │
│          例如: ["摘要1", "摘要2", "摘要3", "摘要4"]               │
└───────────────────────────────┬─────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│          步骤2: 二叉树归并合并摘要 (while length > 1)             │
│                                                                  │
│  第1轮: 4个摘要 → 2个摘要                                        │
│  ┌──────────────┐  ┌──────────────┐                             │
│  │ "摘要1"      │  │ "摘要2"      │                             │
│  │      +       │  │      +       │  ← 并发LLM调用              │
│  │ "摘要3"      │  │ "摘要4"      │                             │
│  └──────┬───────┘  └──────┬───────┘                             │
│         │                 │                                      │
│         ▼                 ▼                                      │
│  ┌──────────────┐  ┌──────────────┐                             │
│  │ "合并摘要A"  │  │ "合并摘要B"  │                             │
│  └──────────────┘  └──────────────┘                             │
│                                                                  │
│  第2轮: 2个摘要 → 1个摘要                                        │
│  ┌──────────────────────────────┐                               │
│  │ "合并摘要A" + "合并摘要B"    │  ← LLM调用                    │
│  └──────────────┬───────────────┘                               │
│                 │                                                │
│                 ▼                                                │
│  ┌──────────────────────────────┐                               │
│  │  "最终社区摘要"              │                               │
│  └──────────────────────────────┘                               │
└───────────────────────────────┬─────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│          步骤3: 生成社区名称                                      │
│          name = await generate_summary_description(summary)      │
│          例如: "科技产品社区"                                     │
└───────────────────────────────┬─────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│          步骤4: 创建 CommunityNode 对象                          │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │ CommunityNode(                                            │  │
│  │   name="科技产品社区",                                     │  │
│  │   summary="最终社区摘要",                                  │  │
│  │   group_id=cluster[0].group_id,                           │  │
│  │   labels=['Community'],                                   │  │
│  │   created_at=now                                          │  │
│  │ )                                                         │  │
│  └───────────────────────────────────────────────────────────┘  │
└───────────────────────────────┬─────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│          步骤5: 创建 HAS_MEMBER 边                               │
│          community_edges = build_community_edges(...)           │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │ (Community)-[:HAS_MEMBER]->(Entity1)                      │  │
│  │ (Community)-[:HAS_MEMBER]->(Entity2)                      │  │
│  │ (Community)-[:HAS_MEMBER]->(Entity3)                      │  │
│  │ ...                                                       │  │
│  └───────────────────────────────────────────────────────────┘  │
└───────────────────────────────┬─────────────────────────────────┘
                                │
                                ▼
                    返回 (community_node, community_edges)
```

## 3. 增量更新流程 (update_community)

```
┌─────────────────────────────────────────────────────────────────┐
│              输入: entity (新增或更新的实体节点)                  │
└───────────────────────────────┬─────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│        步骤1: determine_entity_community(driver, entity)         │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │ 1.1 查询: 实体是否已有社区？                              │  │
│  │     MATCH (c:Community)-[:HAS_MEMBER]->(n {uuid: $uuid})  │  │
│  └───────────────┬──────────────────┬────────────────────────┘  │
│                  │ 有               │ 无                        │
│                  ▼                  ▼                            │
│  ┌─────────────────────┐  ┌──────────────────────────────────┐  │
│  │ 返回该社区          │  │ 1.2 查询邻居的社区并投票         │  │
│  │ is_new = False      │  │ MATCH (c)-[:HAS_MEMBER]->(m)     │  │
│  └─────────────────────┘  │       -[:RELATES_TO]-(n)         │  │
│                           │ 统计每个社区c的出现次数          │  │
│                           │ 选择票数最多的社区               │  │
│                           │ is_new = True                    │  │
│                           └──────────────────────────────────┘  │
└───────────────────────────────┬─────────────────────────────────┘
                                │
                                ▼
                        找到社区了吗？
                                │
                ┌───────────────┴───────────────┐
                │ 否                            │ 是
                ▼                               ▼
┌─────────────────────────┐   ┌─────────────────────────────────────┐
│ 返回 ([], [])           │   │ 步骤2: 合并摘要                      │
│ (没有合适的社区)        │   │ new_summary = summarize_pair(       │
└─────────────────────────┘   │   entity.summary,                   │
                              │   community.summary                 │
                              │ )  ← LLM调用1                       │
                              └────────────┬────────────────────────┘
                                           │
                                           ▼
                              ┌─────────────────────────────────────┐
                              │ 步骤3: 生成新名称                    │
                              │ new_name =                          │
                              │   generate_summary_description(     │
                              │     new_summary                     │
                              │   )  ← LLM调用2                     │
                              └────────────┬────────────────────────┘
                                           │
                                           ▼
                              ┌─────────────────────────────────────┐
                              │ 步骤4: 更新社区对象                  │
                              │ community.summary = new_summary     │
                              │ community.name = new_name           │
                              └────────────┬────────────────────────┘
                                           │
                                           ▼
                              ┌─────────────────────────────────────┐
                              │ 步骤5: 处理成员边                    │
                              │ if is_new:                          │
                              │   创建并保存 HAS_MEMBER 边          │
                              │   (Community)-[:HAS_MEMBER]->(Entity)│
                              └────────────┬────────────────────────┘
                                           │
                                           ▼
                              ┌─────────────────────────────────────┐
                              │ 步骤6: 生成 embedding                │
                              │ community.generate_name_embedding() │
                              └────────────┬────────────────────────┘
                                           │
                                           ▼
                              ┌─────────────────────────────────────┐
                              │ 步骤7: 保存到数据库                  │
                              │ await community.save(driver)        │
                              └────────────┬────────────────────────┘
                                           │
                                           ▼
                              返回 ([community], [edge])或([community], [])
```

## 4. 标签传播算法 (label_propagation)

```
┌─────────────────────────────────────────────────────────────────┐
│     输入: projection = {uuid: [Neighbor(uuid, edge_count)]}     │
│     例如: {                                                      │
│       "A": [Neighbor("B", 2), Neighbor("C", 1)],                │
│       "B": [Neighbor("A", 2), Neighbor("D", 3)],                │
│       "C": [Neighbor("A", 1), Neighbor("D", 2)],                │
│       "D": [Neighbor("B", 3), Neighbor("C", 2)]                 │
│     }                                                            │
└───────────────────────────────┬─────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│          初始化: 每个节点分配独立社区                             │
│          community_map = {                                       │
│            "A": 0, "B": 1, "C": 2, "D": 3                       │
│          }                                                       │
└───────────────────────────────┬─────────────────────────────────┘
                                │
                                ▼
                        ┌───────────────┐
                        │ 开始迭代      │
                        └───────┬───────┘
                                │
┌───────────────────────────────┼─────────────────────────────────┐
│                               ▼                                  │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ 第1轮迭代                                                │    │
│  │                                                          │    │
│  │ 节点A: 邻居B(社区1, 权重2) + 邻居C(社区2, 权重1)        │    │
│  │        → 选择社区1 (权重2最大)                          │    │
│  │                                                          │    │
│  │ 节点B: 邻居A(社区0, 权重2) + 邻居D(社区3, 权重3)        │    │
│  │        → 选择社区3 (权重3最大)                          │    │
│  │                                                          │    │
│  │ 节点C: 邻居A(社区0, 权重1) + 邻居D(社区3, 权重2)        │    │
│  │        → 选择社区3 (权重2最大)                          │    │
│  │                                                          │    │
│  │ 节点D: 邻居B(社区1, 权重3) + 邻居C(社区2, 权重2)        │    │
│  │        → 选择社区1 (权重3最大)                          │    │
│  │                                                          │    │
│  │ 更新后: {"A": 1, "B": 3, "C": 3, "D": 1}                │    │
│  │ 有节点改变社区? 是 → 继续                               │    │
│  └─────────────────────────────────────────────────────────┘    │
│                               │                                  │
│                               ▼                                  │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ 第2轮迭代                                                │    │
│  │ (类似的投票过程...)                                      │    │
│  │ 更新后: {"A": 3, "B": 3, "C": 3, "D": 3}                │    │
│  │ 有节点改变社区? 是 → 继续                               │    │
│  └─────────────────────────────────────────────────────────┘    │
│                               │                                  │
│                               ▼                                  │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │ 第3轮迭代                                                │    │
│  │ 所有节点保持社区3不变                                    │    │
│  │ 有节点改变社区? 否 → 收敛！                             │    │
│  └─────────────────────────────────────────────────────────┘    │
└───────────────────────────────┬─────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│          转换为集群列表                                          │
│          community_cluster_map = {                               │
│            3: ["A", "B", "C", "D"]                              │
│          }                                                       │
│          返回: [["A", "B", "C", "D"]]                           │
└─────────────────────────────────────────────────────────────────┘
```

## 7. 性能对比：全量 vs 增量

```
场景: 100个实体，已分为5个社区，现在添加1个新实体

┌────────────────────────────────────────────────────────────┐
│                     全量重建                                │
├────────────────────────────────────────────────────────────┤
│ 1. 重新检测社区 (标签传播)                                 │
│    - 构建101×101邻接图                                      │
│    - 迭代传播 (多轮)                                        │
│                                                             │
│ 2. 重新构建所有社区摘要                                     │
│    - 社区1: log₂(20) = 5轮 × (10次LLM调用)                 │
│    - 社区2: log₂(20) = 5轮 × (10次LLM调用)                 │
│    - 社区3: log₂(20) = 5轮 × (10次LLM调用)                 │
│    - 社区4: log₂(21) = 5轮 × (11次LLM调用) ← 新成员        │
│    - 社区5: log₂(20) = 5轮 × (10次LLM调用)                 │
│                                                             │
│ 总计: ~51次LLM调用                                          │
│ 时间: 假设每次LLM调用1秒 → 51秒 (如果串行)                 │
│       即使并发，也需要多轮 → 约10-20秒                      │
└────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│                     增量更新                                │
├────────────────────────────────────────────────────────────┤
│ 1. 确定社区归属                                             │
│    - 查询邻居社区 (1次DB查询)                               │
│    - 投票决定 (内存计算)                                    │
│                                                             │
│ 2. 合并摘要                                                 │
│    - 1次LLM调用: 新实体摘要 + 社区摘要                      │
│                                                             │
│ 3. 生成名称                                                 │
│    - 1次LLM调用: 从新摘要提取名称                           │
│                                                             │
│ 4. 更新embedding + 保存                                     │
│    - 1次embedding调用 + 2次DB写入                           │
│                                                             │
│ 总计: 2次LLM调用 + 1次embedding + 2次DB操作                 │
│ 时间: 约2-3秒                                               │
└────────────────────────────────────────────────────────────┘

性能提升: 10-20x 更快！
```

## 8. 决策树：何时使用哪种操作

```
                        开始
                          │
                          ▼
            ┌─────────────────────────┐
            │ 图数据库中有社区吗？     │
```
